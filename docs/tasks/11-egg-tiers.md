# タスク 11: 輪の演出の段階を整理し、演出を作り込む(6件以上を最上位にまとめる・波紋と時間の設計)

CLAUDE.md と SPEC.md(6.11・12章)と、`docs/tasks/10-loop-easter-egg.md`(末尾の経過・10c まで)を読んでから着手すること。
前提: 10(輪を閉じたときの演出)が完了し、push 済みであること

## 背景と目的

10 では、輪の長さに応じて色を一方向に進め(3=黄 → 4=黄緑 → 5=緑 → … → 9=青寄り)、6件以上でカメラワークを行うようにした。

10a の見立て(保存した長い経路10本、`neighborLimit` 24)では、5件の輪を閉じられる候補は30時点のうち2件だけだった。
6件以上はさらに少なく、7件以上は狙ってもまず届かないと考えられる。7〜9件用に細かく分けた色は、誰も見ない色になる。

そこで、利用者と次のとおり決めた(2026-09-27):

- **6件を実質的な最大(最上位の段階)とする**。段階は「3=黄、4=黄緑、5=緑、6以上=最後の1色 + カメラワーク」の4つにまとめる
- 7件以上は、6件と同じ色・同じ演出にする。長さの違いは、左上の `LOOP CLOSED // N NODES` の数字で伝わる
- 段階を少なくするのは、規則に気づいてもらいやすくするためでもある
- 6件にするか7件にするかは利用者も迷っている。そのため、長い経路で6件以上・7件以上の輪がどのくらい起きるかを数え、**数字だけ報告する**(境目は変えない)

さらに、演出そのものを作り込む(2026-09-27 利用者の追加依頼)。今は「輪の記事が動く(6件以上の並べ替え)」と「カメラワーク」だけで見せているが、
各記事から波紋が広がるなど、気持ちよさと驚きが伝わる演出にする。そのために、**人が気持ちよさや驚きを感じる時間の長さを先に決め、その時間の中で見せる中身を割り当てる**(4章)。

あわせて、これまでの議論で「後で決める」とした宿題を、00-workflow.md に一覧として残す。
会話の記録はセッションをまたいで残らないので、リポジトリに書いておかないと忘れられるため。

## やること

### 1. 色の段階をまとめる

- 輪の長さ6以上は、すべて同じ色にする。色は、今の9件の色(青寄り)を使う。3〜5件の色は変えない
- 色の定数(`EGG_COLORS` など)を、4つの段階に合わせて整理する。長さから色を返す関数(`eggColorFor` など)は、6以上ならどの長さでも同じ色を返す
- カメラワークの境目 `EGG_CINEMATIC_MIN` は 6 のまま変えない
- 演出の長さ・光の走り方・並べ替えなど、色以外は変えない
- 定数のコメントに、4段階にまとめた理由(上の背景)を残す

### 2. 長い経路で、6件以上の輪の起きやすさを数える(報告だけ)

- 中心7〜8件の長い経路を、09 と同じ2種類の歩き方で作り、展開結果を保存する
  - 歩き方1: 毎回、まだ通っていない子のうち、関連スコアがいちばん高い記事へ進む
  - 歩き方2: 毎回、抽選の枠から出た子(11位以降)のうち、いちばん順位が高い記事へ進む
- 開始記事は、今ある経路の開始記事から4〜5件選ぶ
- 展開結果は、Node で間隔をあけて一度だけ取り、`tests/fixtures` に保存する(09 と同じやり方)
- `neighborLimit` は rev5 と同じ 24 で数える。参考として 40 も並べる
- 数えるもの: 経路の各時点で閉じられる輪を長さ別に(3 / 4 / 5 / 6 / 7以上)。輪を閉じられる時点の数と、候補の数の両方
- 結果は `docs/tasks/11-report-loops.md` に書く。**`EGG_CINEMATIC_MIN` は変えない**

### 4. 演出を作り込む(時間の設計と中身)

#### 4.1 時間の考え方

演出の長さは、次の考え方で決める。

- **起きる頻度で長さを変える**: 3〜5件はよく起きる(3件目以降の約4割の時点で3件の輪を閉じられる)。毎回散歩を止めると邪魔になるので、短く切れ味よくする。
  6件以上はめったに起きないご褒美なので、長めに見せてよい
- **人が待てる長さの目安**: 操作への反応は約0.1秒以内なら即座に感じ、約1秒までなら考えの流れが途切れず、約10秒を超えると注意がよそへ移る、とよく言われる。
  3〜5件は2.5秒以内、6件以上は8秒以内に収める。どちらも、ドラッグ・ホイール・キーで早送りできる(今までどおり)
- **驚きは「始まりの一瞬」で決まる**: 白一色の画面に色が付く瞬間が、いちばんの驚きになる。始まりは補間せず一瞬で色を付け、ほんの少し(0.1〜0.3秒)止めて「何か起きた」と感じる間を作る
- **気持ちよさは「リズム」と「締め」と「余韻」で決まる**: 光が記事に届くたびに波紋が出るという規則的なリズム、一周して戻ったときの一度だけの大きな締め、ゆっくり消える余韻(0.5〜1秒)。
  急に終わると安っぽく見えるので、余韻を省かない
- **動きの緩急**: 始まり(色が付く・波紋が出る)は勢いよく出てゆっくり止まる動き(ease-out)。カメラと並べ替えは、ゆっくり動き出してゆっくり止まる動き(ease-in-out)にする

#### 4.2 使う表現(依存は増やさない。three.js と DOM だけで作る)

| 表現 | 中身 | 作り方の目安 |
|---|---|---|
| 小さな波紋 | 光が輪の記事に届いた瞬間、その記事から輪の色のリングが広がって消える | 中空のリングの画像を使うスプライト。大きさを広げながら、不透明度を下げる(約0.5秒) |
| 大きな波紋(締め) | 光が一周して戻り先に戻った瞬間に、一度だけ広がる | 3〜5件は戻り先から、画面上で大きめのリング。6件以上は輪の面の上に、重心から広がる平らなリング(斜め上から見ると楕円になり、立体感が出る) |
| 輪が揃って光る | 締めの瞬間に、輪の線がすべて一度だけ最大の明るさになり、余韻でゆっくり戻る | 今の線の色と明るさを使う |
| 端末風の文字 | `LOOP CLOSED // N NODES` を、1文字ずつ打ち込むように出す(6件以上だけ) | 今の左上の一行を、30ミリ秒前後に1文字ずつ出す |
| 走査線(6件以上だけ) | 締めの瞬間に、白い1pxの横線が画面を上から下へ一度だけ通り過ぎる | DOM の重ね表示。グラデーションは使わない |

背景のグリッドの円を、内側から順に一度だけ明るくして波のように見せることができれば、足してよい(作りが大きくなるなら省いてよい。作業の最初に今の作りを調べて判断し、報告に書く)。

#### 4.3 時間割

どの長さも定数にし、決めた値と理由をコメントに残す。時間割は純粋関数で決め(`src/utils/eggMotion.js`)、テストで確かめる。

**3〜5件(合計 約2.3秒。カメラは今までどおり、収まらなければ小さく引くだけ)**

| 時間 | 見せるもの |
|---|---|
| 0.00〜0.15秒 | 一瞬で輪に色が付き、少し止まる(驚き) |
| 0.15〜1.35秒 | 光が戻り先から輪を一周する。記事に届くたびに小さな波紋 |
| 1.35〜1.60秒 | 締め: 戻り先から大きな波紋、輪の線が揃って一度だけ光る |
| 1.60〜2.30秒 | 余韻: 色と明るさがゆっくり戻る |

**6件以上(合計 約7秒)**

| 時間 | 見せるもの |
|---|---|
| 0.0〜0.3秒 | 一瞬で輪に色が付き、動きが止まる(驚き)。輪以外が薄くなり始める |
| 0.3〜1.3秒 | 輪を正多角形に並べ替え、カメラが斜め上の位置へ移る(10c のとおり) |
| 1.3〜1.8秒 | 溜め: 輪の記事が戻り先から順に灯り、それぞれ小さな波紋を出す |
| 1.8〜5.4秒 | カメラが一周する。光が輪を走る。1周目だけ、記事に届くたびに小さな波紋。2周目以降は波紋を出さず、なめらかに走らせる |
| 5.4〜6.0秒 | 締め: 光が戻り先に戻った瞬間に、輪の面の上の大きな波紋・輪が揃って光る・走査線を一度だけ。左上の文字の打ち込みが始まる |
| 6.0〜7.0秒 | 余韻: 少し保ったあと、輪を元の位置へ戻し(10c のとおり)、ほかの記事の明るさを戻す |

#### 4.4 安全

- 画面の広い範囲が明るくなったり暗くなったりする変化(大きな波紋・輪が揃って光る・走査線)は、それぞれ演出の中で一度だけにする
- 小さな波紋は、画面のごく狭い範囲の変化にとどめる(目安: 直径120px以下)。1秒あたりに新しく出る数も、テストで上限を確かめる
- 1秒間に3回を超えて点滅させない、という今までの決まりを守る
- `prefers-reduced-motion: reduce` のときは、波紋・走査線・文字の打ち込みを行わない。色を付けて消えるのと、左上の文字を一度に出すことだけにする(今までどおり、カメラワークと並べ替えも行わない)
- 音は使わない

#### 4.5 確かめ方

- `window.__viz.egg(3)`〜`egg(9)` で、上の時間割どおりに流れること
- 見た目の良し悪しは、利用者が画面で見て判断する。報告には、pc とスマホ横画面の両方で、驚き・リズム・締め・余韻のそれぞれの瞬間の画面を添える
