## 4章の結果(rev5 と既定の切り替え)

- `src/constants.js` に `REV5_NEIGHBOR_LIMIT = 24` と理由、段階の境目を変えなかった理由を足した。`src/config/presets.ts` に `rev5` を足し、`DEFAULT_PRESET = 'rev5'`
- 回帰: current・rev2・rev3・rev4 の配置(一度に組んだ場合・1件ずつ歩いた場合)と最初のカメラ距離(復元・検索)が、
  タスク08 完了時のコミット(aa0d755)のコードで求めた値と末尾の桁まで一致する(22経路 × 4 プリセット。`tests/rev5.test.js`・`tests/fixtures/camera-layout-at08.json`)
- ブラウザで `?preset=` の無い URL(初音ミク → 鏡音リン・レン)を開くと rev5(子 24件ずつ・`cameraFit` d・到着時の強調 on)で表示され、Console にエラーは出なかった。
  同じ画面から保存した展開結果で `measure({ presets: ['rev4', 'rev5'], allowDifferentRanking: true })` を実行し、rev5 の数字が上の n24 と一致することを確かめた(work・science の復元・phone の M5 初期: 16 → 6、19 → 9)

### `?preset=` の無い URL(SPEC 12.3)

- 歩いたときに URL へ書くのは `start` と `path` だけで、`preset` はデバッグパネルで設定を変えたときしか書かない。
  **公開サイトで歩いて共有された URL は、ほぼすべて `preset` を持たない**。切り替え後はそれらが rev5 で開く
- 経路は壊れない: 復元は `path` の記事を1件ずつ取り直すだけで、前の記事の子に含まれているかは見ない(中心同士の線は常に引く)。
  前の記事の25〜40件目だった記事へ進んだ URL でも開ける
- 見た目は変わる: 子が24件(40件のときの先頭24件と同じ顔ぶれ)になり、段階・カメラ・到着時の強調が入る。
  共有したときと同じ見た目は `&preset=rev2` を足すと開ける
- リポジトリ内の文書(README など)に載っている URL は、どれも `preset` 付きか開発用(localhost)で、書き換えが要るものは無かった
